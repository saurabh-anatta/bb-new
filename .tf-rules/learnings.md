## Recent
[chat] Horizon's `assets/base.css` has a global override `.shopify-section:not(.header-section) :is(.section, .cart-summary) { background: transparent; }` that strips the background from any section with class `.section` whose `.shopify-section` wrapper lacks the `.header-section` class. The pattern relies on a sibling `<div class="section-background color-...">` to render the actual color. Any header-area section (e.g. `header-announcements.liquid`, promo-bar) MUST declare `"class": "header-section"` in its schema so Shopify adds that class to the wrapper — otherwise the color scheme background disappears even though `<div class="section-background">` exists.
